# Фотографии за галеријата на насловната

Ставете 7 слики овде и тие автоматски ќе се појават во табот „Галерија од
гостите“ на насловната страница, на местото на цртежите.

    guests-1.jpg … guests-7.jpg

Квадратни, идеално 800×800 или поголеми (се сечат со `object-fit: cover`).
Списокот се чита во `src/components/landingPage/PlannerTabs.vue` → `GALLERY_PHOTOS`.

## Зошто тука нема слики — што е проверено

| извор | исход |
|---|---|
| `source.unsplash.com` | угасен (503) |
| Unsplash внатрешен API (`/napi/search`) | 401 — бара клуч |
| Unsplash / Pexels страници за пребарување | се исцртуваат преку JavaScript; ништо не се извлекува од HTML |
| `loremflickr.com` | работи, но ги пече лиценцата и авторот во пикселите; вратените слики беа `cc-nc-nd` и `cc-sa` |
| **`api.openverse.org`** | **работи, без клуч, филтрира по лиценца** |

Openverse е единствениот употреблив без клуч. Со филтер `license=cc0,pdm` —
единствените две лиценци што дозволуваат комерцијална употреба без наведување
автор — за „wedding reception“ има околу 240 слики, но фондот е претежно
скенирани фотографии од 1980-тите, оштетени стаклени плочи и аматерски снимки.
Прегледани се четири: најдобрата беше позирана снимка покрај дрвена ограда.
Не одговара на регистарот на дизајнот.

## Најбрз пат до чисти слики

Бесплатен API-клуч, две минути:

- **Unsplash** — https://unsplash.com/developers → „New Application“. Лиценцата
  дозволува комерцијална употреба без наведување автор.
- **Pexels** — https://www.pexels.com/api/ → „Get Started“. Истото.

Со клуч може да се повлечат чисти слики без воден жиг, по тема.

Забелешка: CC0 и PDM ја покриваат авторската, не и правото на ликот на
снимениот човек. Фотографиите на Unsplash и Pexels се снимани за сток-употреба,
што е дополнителна причина тие да се подобри за комерцијална страница од
случајна јавна фотографија од нечија свадба.
