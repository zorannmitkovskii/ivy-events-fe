## 5. Final Recommendations

---

**How to keep homepage broad:**
- The homepage H1 and meta title should always combine "digital invitations" with "event planner/planning" -- never narrow to a single event type.
- Mention specific event types only in body copy lists (e.g., "for weddings, birthdays, graduations, and more") but never in H1, meta title, or primary headings.
- Homepage FAQs should cover platform-level questions (what is it, how does it work, pricing, sharing) rather than event-specific questions.
- Use internal links from the homepage to direct event-type traffic to the correct category or event pages.

**How to keep category pages specific:**
- Each event page (Wedding, Birthday, Graduation) should have its own unique H1 containing the event type keyword.
- Never duplicate the homepage H1 structure on category pages.
- Category pages should use long-tail secondary keywords that include the event type (e.g., "digital wedding RSVP," "birthday guest list," "graduation announcement").
- The Event Category hub page uses "for every event" language -- it never targets a single event type as its primary keyword.

**How to localize keywords between English and Macedonian:**
- Do not translate keyword-for-keyword. Research how Macedonians naturally describe events: "свадба" (not "венчање"), "роденден" (not "роденденска прослава" unless appropriate), "матура" for high school, "дипломирање" for university.
- Use preposition-based keyword forms when they are more natural in Macedonian: "покани за свадба" rather than forcing "свадбени покани" everywhere, though both are valid.
- RSVP is understood in Macedonia but always pair it with a Macedonian explanation: "RSVP потврда" or "потврда за присуство."
- "Планирање настани" and "организирање настани" can both be used, but "планирање" is closer to the English "planning" and is commonly understood.
- Test keyword volumes for both "дигитални покани" and "онлајн покани" -- both are valid in Macedonian, and using both as primary + secondary captures more search surface.

**Internal linking recommendations:**
- Homepage links to: Event Category Page, Wedding Page, Features, Pricing.
- Event Category Page links to: Wedding Page, Birthday Page, Graduation Page (and future category pages).
- Each event page links to: Event Category Page (breadcrumb), Features, Pricing, and relevant FAQ anchors.
- FAQ Page links to: Homepage, Event Category Page, Wedding Page, and any feature page referenced in answers.
- Footer navigation should include all public pages for crawlability.
- Use descriptive anchor text that includes the target page keyword (e.g., "digital wedding invitations" as anchor text linking to the wedding page).

**Future category page suggestions:**
- Baby Showers -- "digital baby shower invitations" / "покани за бејби шауер"
- Anniversaries -- "digital anniversary invitations" / "покани за годишнина"
- Corporate Events -- "digital corporate event invitations" / "покани за корпоративни настани"
- Conferences -- "digital conference invitations" / "покани за конференции"
- Private Dinners -- "digital dinner party invitations" / "покани за приватна вечера"
- Each new category page should follow the same silo structure: unique H1 with event type, linked from the Event Category hub page, with no keyword overlap with existing pages.
